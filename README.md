# Leshuang (Lottie) Wang — Marketing Portfolio

Static, GitHub Pages-ready version of the marketing portfolio.

## Publish with GitHub Pages

1. Create a GitHub repository and push this project to its `main` branch.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder, then save.

GitHub will publish the homepage from `index.html`. The included `.nojekyll` file is required so GitHub Pages serves the `_next` asset folder correctly.

## Files

- `index.html` — portfolio homepage, including English/Chinese language switching
- `lifestream-valentines.html` — linked Lifestream feature article
- `images/` and `_next/` — local image, style, and script assets
